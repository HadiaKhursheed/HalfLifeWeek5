# Lasercut Panels Table Lamp
Inspired by many cool cyberpunk themed lamps on Pinterest I designed my own lamp in Autodesk Fusion.


# Software used
1. Inkscape- To design lamp panel patterns & exporting in plain svg file
2. Autodesk Fusion- To place svg patterns on box shaped model

# Model specifications
1. Size- 25cm(height), 10cm(width) and 10 by 10cm(base)
2. Joints- Finger/Box joint
3. Material used- MDF 2mm as outerbox & Acrylic 2mm White as light diffuser
